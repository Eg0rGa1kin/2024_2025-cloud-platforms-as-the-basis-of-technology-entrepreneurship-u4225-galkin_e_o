Цель работы: Научиться использовать Google Cloud Storage для создания бакетов, загрузки файлов, организации структуры файлов и настройки доступа.  

Google Cloud Storage — это облачное хранилище данных, предоставляемое Google в рамках платформы Google Cloud. Оно предназначено для хранения и управления большими объемами данных, включая файлы, изображения, видео и другие типы информации.  

Бакет (bucket) в контексте Google Cloud Storage, представляет собой контейнер для хранения объектов (файлов).
